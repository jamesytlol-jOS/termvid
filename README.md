# termvid
termvid is a tool for watching videos in your terminal

# what do i need
- terminal
- python (with opencv2)
- ffmpeg
- a video
- git (optional)

# how do i do it
1. install python3, python3-opencv, ffmpeg, (optional) git
2. download termvid by downloading here or with git by typing " git clone https://github.com/jamesytlol-jOS/termvid "
3. place your video in the same folder as termvid.py
4. run " python3 termvid.py video.mp4 " (make sure video.mp4 is replaced with actual filename)
5. watch your video

# where can i run it
any linux that supports python3, python3's opencv 2 and ffmpeg
